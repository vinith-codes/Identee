Do this once per style

Styles: switch a garment on for the shop

Menu → Shop your IDENTEE → Styles

Oversized and Round Neck (Men and Women) are already on. You only come here to add a new style, change which colours are sold, or change a price.

  1. First make the garment live in Create your IDENTEE as usual: White front and back hanger photos, colours, sizes, size chart, print areas, price.
  2. Open Styles. Your garment is under “Not used for shop tees”. Press Show them and open it.
  3. Switch Use for shop tees on.
  4. Check the name the shop shows (“Polo”), who it is for, its place in the list, the shop category, and the fit words.
  5. Tap colours to tick or untick them. Only ticked colours are sold in the shop.
  6. Press Save.

Two garments, one name. Men's and Women's Round Neck both use the name “Round Neck”, so the shop shows one Round Neck tab. Give a new garment the same name only if it should join that tab.

One design

Add a tee

Menu → Shop your IDENTEE → Add a tee

  1. Collection and name. Pick a collection (or “+ New collection…”) and type the tee's name. You see the full shop name under it, for example AYYAPPA · Tiger Saranam.
  2. Pictures. Add the front picture, the back picture, or both. Use full-size files; they are never made smaller. Remove background is there if a picture has a plain background.
  3. Where it prints. Front: small logo on the chest, centre of the chest, big on the front, or nothing. Back: big on the back, small under the collar, or nothing. Tick Lock the front picture if customers must not change it (like the GTA logo).
  4. Styles, colours and price. Tick each style to make (Oversized, Round Neck…). Colours and prices come from Styles; untick a colour or type a price only if this tee is different.
  5. Press See it on the tee to check the look, then Make. One draft is made per ticked style.

Picture sharpness. Next to each picture you see its print sharpness (DPI). Green is fine. Orange means it may print soft, so use a bigger file if you have one.

Many designs at once

Add many tees

Menu → Shop your IDENTEE → Add many tees

Same idea as Add a tee, but the settings are chosen once for all the tees.

  1. Choose the collection, where they print, and the styles. These apply to every tee in this batch.
  2. Name your files before you start: tiger-front.png and tiger-back.png become one tee called “Tiger”. A file with only one side is fine.
  3. Drop all the pictures in. Each tee becomes a row. You can fix a name, press Swap front/back, or Remove a row.
  4. Pictures whose name doesn't end in -front or -back go to the loose tray. For each one, choose “front of a new tee”, “back of Tiger”, or the bin.
  5. Fix any red notes (no name, same name twice, picture too small, already made). Then press Make all. You can press Stop any time.

If some fail. The good ones are kept. Press Make all again; only the missing ones are made, and they join the same design.

Check and show

Menu → Shop your IDENTEE → Check and show

Every new tee waits here as a draft. Tees of one design sit together (Oversized, Round Neck Men, Round Neck Women…).

  1. Click a picture to see it big. Use the colour dots to look at each colour.
  2. Happy? Press Show in the shop on one tee, or Show all for the whole design. It is live at once.
  3. Print in the wrong place or too big? Press Fix. It opens the tee in the Studio so you can move or resize the print.
  4. Don't want it? Press Throw away.
  5. Many at once: tick tees and use Show ticked in the shop or Throw away ticked.

Old tees, new style

+ style in Manage the shop

Menu → Shop your IDENTEE → Manage the shop

Use this when a tee is already in the shop and you want it on another style too. For example, all your Oversized GTA tees on the new Polo.

  1. For one tee: press + style on its row.
  2. For many: tick them, then press + Add to a style… at the top.
  3. Choose the style. It uses the same pictures and print places, and the colours that style sells.
  4. Press Make. Designs that already have that style are skipped, and you are told how many.
  5. The new tees are drafts. Press Open Check and show → to look and put them live.

Only the main prints are copied (front and back). If a tee had extra prints, like a sleeve, you see a note, and you can add them with Fix.

All products

The list of every tee in the shop. Use it to search, restock a size, or hide a tee. Shop your IDENTEE is only for printed design tees, so the old Add a product and Add many (spreadsheet) are gone from the menu. To add a tee, use Add a tee or Add many tees.

Everyday jobs

A new design for the shop

One picture set, on every style.

  1. Add a tee
  2. Tick all the styles
  3. See it on the tee → Make
  4. Check and show → Show all

A whole new collection

Twenty designs from the designer.

  1. Name files name-front / name-back
  2. Add many tees → + New collection
  3. Drop them in → Make all
  4. Check and show → Show ticked

Launch a Polo

A new garment in the shop.

  1. Make it live in Create your IDENTEE
  2. Styles → switch on → Save
  3. Manage the shop → tick tees → + Add to a style
  4. Check and show → Show all

Stop selling a colour

Pink isn't selling on Round Neck.

  1. Styles → Round Neck
  2. Tap Pink to untick it
  3. Save. The shop hides Pink within a minute

Good to know

  • Making tees never changes the shop. Only Show in the shop does.
  • A tee already made in a style is skipped, so pressing Make twice won't make doubles.
  • If something fails, press the button again. Only the missing tees are made.
  • Prices come from Styles unless you type a price on the tee.
  • Pictures are always kept full size, so prints stay sharp.
  • The shop looks the same to customers. Only these admin screens are new.
